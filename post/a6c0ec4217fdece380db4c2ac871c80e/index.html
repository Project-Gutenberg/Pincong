1. 总结

从周末的线下商场中可以轻松发现当下

年轻情侣出游数 < 家庭集体出游数

女性消费（化妆品、服装、首饰）< 儿童消费（游乐设施、儿童体验、玩具、教培）

女性服装店内消费者数量 < 儿童服饰店内消费者数量

情侣约会大餐店 < 商场内街边小吃

适合约会餐饮店（甜品、法式、日式、欧式、韩式）< 自助餐（AA 制）< 街边小吃（麻辣烫、米线、兰州牛肉面、排骨米饭、拌饭）

情侣餐饮经济（甜品、法式）< 单身餐饮经济（自助旋转小火锅、回转寿司）

高价服装店、首饰店 < 低价服饰店、低价首饰店

结婚消费（金店）< 情侣消费（餐饮店、服装店）< 男性消费（手机、汽车）< 儿童消费（娱乐、体验）< 家庭消费（每种店都有一家三口、一家几口消费）

2. 当下特点

简单来说就是男性向女性的转移支付停止之后

传统女性消费品，化妆品、服饰、首饰老三样消费直线下降，未观察到改善或触底信号。

传统男性消费品**，手机、汽车、电脑、3C 配件**消费小幅上涨，并且单价低的 3C 配件、手机、电脑消费涨幅大于单价高的汽车消费。

传统情侣餐饮消费品，约会店、网红店、大餐店几乎消失，未观察到改善现象

近年单身餐饮消费品，回转寿司、自助小火锅、米线、麻辣烫、兰州牛肉面、猪脚砂锅等挤占原本情侣餐饮消费品

消费品整体趋势走向低价、廉价、小量、高频、高性价比的方向。大额消费，尤其是以情侣、结婚两个市场为主的所有消费都崩溃了。

有点类似西方经济学中的口红效应，但是叠加国内男女 OO 问题，连口红都卖不出去了。（廉价杂货店里未观察到化妆品及口红）

3. 未来趋势

消费向低价、廉价、小量、高频、高性价比的方向加速前进，在福利体制、全民发钱、科技爆发、劳动力价格上涨、对外掠夺等事件未发生的情况下，通货紧缩会更加严重。

从男性消费中可以发现男性只是暂停了转移支付但是并没有肆意的将节省下来的钱消费掉，有部分男性对于女性还有所期待，对婚姻还有所期待。这部分如果抢救一下还是能凑出一部分婚育人群，但是观察不到希望。

从金店消费者数量可以发现今年结婚率应该是断崖式下降，并未发现触底或反弹信号，很有可能维持在极低位置（约等于 0 附近）

结婚率下降带来的就是出生人口数下降，在商场里能看到 3~6 岁，6~12 岁，12~18 岁三个阶段的孩子，但是孕妇 0，婴儿车 3。

从电玩店的人流和偏爱的游戏机能够看出当下的年轻男女压力都非常大，需要情绪出口。
